# PlacePrep

**PlacePrep is an all-in-one placement preparation platform designed to help students prepare for company-specific recruitment, technical interviews, coding rounds, resumes, and placement assessments.**

**Live Demo:** https://akankshk08.github.io/Placeprep/

---

## API Key Requirement

PlacePrep uses the **Google Gemini API** to power its AI-based learning and preparation features.

**An API key is required to use the application.**

### How to Access

1. Open the [Live Demo](https://akankshk08.github.io/Placeprep/).
2. Enter your **own Google Gemini API key** when prompted.
3. Save the key to access the application.

> **Important:** PlacePrep does not provide API keys. Users must use their own Google Gemini API key. The key is stored locally in the user's browser and is used to communicate directly with Google Gemini. PlacePrep does not require login or user accounts.

## Privacy

* No login or signup
* No backend database
* No user accounts
* User data such as bookmarks, tracker information, and resume data is stored locally in the browser
* AI requests are made directly to Google Gemini using the API key provided by the user

## Goal

PlacePrep brings **company research, AI-assisted learning, interview practice, resume preparation, resources, and placement planning into one platform** to make placement preparation more structured and accessible.
